# ToothFairyVision
a dental computer vision project



## Dataset

This project uses [PanoraDent](https://data.mendeley.com/datasets/2w8ppb94s4/1), a publicly available dataset of 1,295 anonymised dental panoramic radiographs (OPGs). It contains 8,204 bounding-box annotations across 11 classes, covering dental findings such as caries, missing teeth, fractures and impacted teeth. Annotations are provided in YOLO and COCO formats, alongside predefined training, validation and test splits. The dataset is licensed under CC BY 4.0.

**Reference:** Kohinoor et al. (2026), [PanoraDent](https://doi.org/10.17632/2w8ppb94s4.1).
